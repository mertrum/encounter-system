Encounter System
================

This module was built from the supplied Forge export. It includes the exported
encounter tables, the current Encounter Generator macro, a macro
compendium, a table compendium, and a scene-control button under the
Measurement/Tools controls.

On first world start, a GM session creates missing tables and the generator
macro. Existing world documents with the same names are left untouched, so
your current edited tables are not overwritten.

The module is system-neutral and is verified for Foundry VTT v14. It does not
require a particular game system. The included tables are fantasy-themed and
can be edited or replaced in the world after installation.

The supplied export contains the current state of the tables, including the full downloaded Stay Small, Stay medium, and Stay Large night tables. In particular,
the exported Forest tables are empty and Marsh, Hills, and Mountains tables
were not present in the export; this package does not invent entries for them.
